# My Childhood

A static HTML and CSS page first built for M05T06 (CSS Overview), deployed
for M07T01 Practical Task 1. The original markup, stylesheet and four local SVG
illustrations are preserved.

## View locally

Open `index.html` in a browser, or run `python -m http.server 8080` in this folder.

## GitHub Pages

Publish the `main` branch, `/` (root) folder. No dependencies, build step or server-side code are required.
